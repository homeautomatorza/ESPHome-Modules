# Samples

Samples are small, focused ESPHome examples.

Use these to learn from one idea without adopting a complete project structure.
They may still depend on framework packages or specific hardware.

These files carry an "it works in my environment" disclaimer. Review the
dependencies, pins, sensors, and safety assumptions before using a sample on
your own device.

## Available Samples

- `earth_tremour.yaml`: a small MPU6050-based tremor detection experiment. This
  is a fun learning sample, not a calibrated safety or seismic monitoring tool.
