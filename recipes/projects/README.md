# Projects

Projects are cookbook-style ESPHome builds that show how framework packages fit
together in a real device.

These are still subject to the "it works in my environment" disclaimer. Treat
them as tested patterns and documentation trails, then review wiring, board
choice, calibration, secrets, and Home Assistant entities for your own setup.

## Available Projects

- [HAZA Room Sense Basic](room_sense_basic/README.md): the first room-monitoring
  project. It will start from Pascal's Guest Room device and migrate it into the
  new framework style.
