# Boilerplates

Boilerplates are starter YAML files for common ESPHome board setups.

Use these when you want a clean base device file and plan to add your own
sensors, peripherals, naming, networking, and project logic.

These files carry an "it works in my environment" disclaimer. Check the board,
pins, packages, ESPHome version, and network settings before using one on your
own hardware.

## Available Boilerplates

- `esphome_c6_f4p0_firebeetle_2_boilerplate.yaml`
- `esphome_c6_f4p0_super_mini_boilerplate.yaml`

- `esphome_esp32_f16p2_firebeetle_2_e_boilerplate.yaml`
- `esphome_s3_f4p2_super_mini_v2_boilerplate.yaml`
