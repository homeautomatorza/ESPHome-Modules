# About

This page is a placeholder for the longer project background.

HAZA started as Pascal's personal ESPHome package framework. The goal was to
reduce repeated YAML, make device projects easier to maintain, and keep common
board, network, sensor, display, and peripheral patterns in reusable modules.

The 2026 rebuild is turning that personal framework into a cleaner public
project with reviewed modules, cookbook examples, honest validation notes, and a
wiki that can grow alongside the code.
