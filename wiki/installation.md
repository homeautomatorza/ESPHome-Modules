# Installation

This page is a placeholder while the full installation guide is being rebuilt.
The goal is to document three practical ways to use the HAZA ESPHome Modular
Framework: downloading a ZIP, cloning the repository, or referencing modules
remotely from ESPHome packages.

## ZIP

Use this option when you want the simplest manual setup:

1. Download the repository ZIP from GitHub.
2. Extract it on your computer.
3. Copy the board, common, peripheral, sensor, or recipe files you need into
   your ESPHome configuration folder.

Detailed screenshots and examples still need to be added.

## Clone

Use this option when you are comfortable keeping a local Git copy of the
framework:

1. Clone the repository with Git or your preferred Git client.
2. Keep the folder somewhere stable on your ESPHome machine or workstation.
3. Copy from it, or reference it locally, as you build devices.

Detailed setup notes still need to be added.

## Remote

Use this option when you want ESPHome to pull packages directly from the GitHub
repository:

1. Reference the required package files from your ESPHome YAML.
2. Pin to a known branch, tag, or commit when stability matters.
3. Update carefully, especially on devices that are already installed.

Working remote package examples still need to be added.
