# Licence

This page is a placeholder for licence and branding notes.

The project uses CC0 1.0 Universal unless a file says otherwise. The full licence
text is in the repository `LICENSE` file.

CC0 covers the project files, but it does not grant permission to use the Home
Automator ZA name, logos, app icons, or branding in modified versions or
redistributions.
