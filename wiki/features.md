# Features

This page is a placeholder for the full feature guide.

The HAZA ESPHome Modular Framework is built around practical reuse, not magic.
It improves day-to-day ESPHome work by making common device patterns easier to
share, review, document, and troubleshoot.

## Feature Areas

- reusable ESPHome packages
- fewer copy-paste blocks
- faster project starts
- board-aware structure
- common network, display, time, and core modules
- reusable sensor and peripheral packages
- boilerplates and cookbook projects
- module metadata and documentation
- honest validation tracking
